# Local Typing Trainer — Project Spec

*A self-hosted, single-user typing-practice app for reading your own documents, modeled on the UI/UX of [Typersguild](https://typersguild.com).*

Source: live walkthrough of Typersguild on 2026-08-31 (landing page, dashboard, book/chapter pages, live typing view, full Settings, Quick Settings drawer, theme picker). Feature list below is a direct inventory of what that site does — flagged wherever something is inferred rather than observed.

---

## 1. Concept

Typersguild's core loop: pick a book → pick a chapter → type it, paragraph by paragraph, with live WPM/accuracy/error feedback → get XP and stats when you finish a paragraph → keep going or leave (progress is saved per-paragraph, so "continue" always resumes exactly where you stopped).

Your version keeps that loop but swaps "100+ classic books" for **your own uploaded documents** (PDF/EPUB/TXT/DOCX/Markdown), and drops the multi-tenant stuff (leaderboards, friends, billing) that only makes sense on a hosted product with strangers on it.

---

## 2. Information Architecture

Five surfaces, same as the source site:

1. **Home / Dashboard** — stats, streak, "continue reading," your library.
2. **Library** — grid of your uploaded documents (replaces "Books").
3. **Document detail** — cover/title, chapter (or section) list with progress, tabs for Chapters / Notes / Highlights.
4. **Reader/Typer view** — the actual typing screen. This is the product.
5. **Settings** — full-page settings with the same section taxonomy Typersguild uses: Appearance, Custom Themes, Stats Card, Audio, Keyboard, Training.

Cut entirely (multi-user features that don't apply to a local single-user app): Friends, Leaderboard, Wiki (community book-of-the-day content), Billing/Premium paywall, Discord/social links.

---

## 3. Dashboard

What Typersguild shows, and what to keep:

- Personalized greeting ("Good Morning, {name}") with avatar.
- Two trend charts: **accuracy** and **WPM**, last 15 sessions, small bar/line chart with a delta badge (e.g. "+2", "-10") against the previous period.
- **Recent Activity** feed: last few typing sessions — document, XP earned, paragraph count, time ago.
- **Vocabulary** strip — chips of words you've typed that the app flagged as notable/uncommon (e.g. "petulance," "desultory"), a nice passive-learning touch. Lets you feel progress beyond WPM.
- **Continue Reading** card: cover thumbnail, title, author, "22/165 pages," "last typed Aug 11," circular % progress ring, and a keyboard-shortcut hint badge (Typersguild uses ⌘+1).
- Daily-activity **heat map** (GitHub-style contribution grid) — drives streaks.

Skip: "Recommended for You" (needs a catalog of many books to recommend from; irrelevant with a personal doc library) and rank/leaderboard position.

---

## 4. Document Detail Page

- Cover (auto-generate a simple geometric placeholder cover if the source has no image — Typersguild does this for public-domain texts), title, author/source, tags (auto-detected genre isn't necessary; could tag by folder or user-entered), page count, estimated read time.
- Truncated description with "Show more" toggle (for uploaded docs: first N words of the doc, or a user-editable blurb).
- **Continue Typing** primary button, with the keyboard-shortcut hint under it (Typersguild: ⌘+Enter).
- Tabs: **Chapters**, **Notes**, **Highlights**. (Drop the **Friends** tab — no social layer.)
- Chapter/section list, each row showing:
  - Status icon: ✓ complete (green), ▶ in-progress, ○ dashed = not started.
  - Title + page/word count.
  - Per-chapter WPM and accuracy once attempted.
  - Aggregate avg WPM / avg accuracy badges at the top of the list.

For your use case, "chapters" = however the uploaded doc gets segmented (see §9 — this is the one piece Typersguild doesn't need to solve, since it only ever ingests pre-chaptered books).

## 5. The Reader/Typer View — this is the important part

### 5.1 Layout & feel

- Minimal, distraction-free: no visible top nav while typing. Just the small wordmark/logo in the top-left; everything else (nav links, XP counter, theme/settings icons) is hidden until you leave the view.
- Monospace font, generous line height, centered single-column text block, dark theme by default.
- Continuous vertical scroll through the chapter — it is **not** a one-paragraph-at-a-time modal. You scroll through prose exactly as you'd read a book; the *current* paragraph is where your cursor is.
- **Completed paragraphs stay visible**, each with a small inline stats line directly beneath it: `⚡ 59 wpm · ⊘ 96.1% accuracy · 🏆 +104 xp`. This is a nice touch — it turns the whole page into a visible progress trail as you scroll, like a typing "diff" of the book.
- Chapter/section headers appear inline in the text (e.g. "CHAPTER II. THE SCIENCE OF DEDUCTION.") and themselves award a small XP bonus just for reaching them.

### 5.2 Live typing feedback

- Caret renders as a thin vertical bar at your exact character position.
- Untyped text is dimmed/muted; typed text is full-brightness.
- Correctly typed characters render in the normal text color.
- **Incorrectly typed characters render in red/orange**, inline, character-by-character — you see your mistake immediately, in place, without a popup or shake animation.
- Spaces you've typed render as a visible underscore-like glyph (`_`) so trailing/leading whitespace errors are visible.
- Typing continues to accept input after an error (default mode) — it doesn't hard-block you unless "Stop on Error" is enabled (§7.5).

### 5.3 The floating toolbar

A vertical stack of icon buttons pinned to the right edge, visible only in the typer view:

| Icon | Function |
|---|---|
| ‹ | Previous chapter/section |
| 📖 | Back to chapter list / table of contents |
| › | Next chapter/section |
| 📄 | Open **Notes** modal (markdown-supported, scoped to this document) |
| ⚙ (sliders) | Open **Quick Settings** drawer (§5.4) |
| 🎧 | Open **Focus Sounds** popover (§5.5) |
| ☸ (lotus) | Toggle **Zen Mode** |

This is the answer to "where's the pause button" — there isn't a literal pause icon. Instead:

### 5.4 Quick Settings drawer

Slides in from the right without leaving the page. Header: "Adjust settings on the fly while typing." Contains a *subset* of the full Settings page, so you never have to break flow to tweak something:

- Font, Font Size (slider)
- **Cursor Motion** (dropdown — e.g. "Smooth" vs presumably "Instant"/"Jump")
- Enable Audio (master toggle) → Typing Sound picker + Error Sound picker (inline, collapses when audio is off)
- Show Keyboard (on-screen keyboard visualizer toggle)
- Enable Training Mode, Ignore Capitalization, Stop on Error, Auto Skip Symbols (toggles, mirrored from Settings)
- "Open Full Settings →" link at the bottom for anything not in this shortlist

### 5.5 Focus Sounds

Separate from the mechanical-keyboard click sound. A small ambient-noise mixer: "Layer a steady backdrop to soften distractions and stay with the page." Observed one preset (Rain — "soft indoor rain with distant thunder") with its own volume slider and a play/pause transport button. Implies a small library of loopable ambient tracks (rain, cafe, white noise, etc.) independent of the typing-click SFX.

### 5.6 Zen Mode

A single toggle (lotus icon) that presumably dims/removes remaining chrome for maximum focus — exact visual effect wasn't fully observable in this walkthrough, but it's a distinct, named "focus" state worth replicating as a simple CSS class that hides secondary UI and darkens the timer/stats overlay.

### 5.7 On what "pause" and "timer" actually turn out to be

Honest finding, since you asked specifically about this: **Typersguild has no visible countdown timer and no explicit pause button** in the typing view. What it has instead:

- **Implicit pause via autosave.** Every paragraph is scored and saved the moment you finish it. There's no "session" you can lose — you can navigate away (or just stop typing) mid-paragraph and nothing is lost except that one in-progress paragraph. The dashboard's "last typed Aug 11" and the chapter list's ▶/✓ icons are how progress persistence is surfaced back to you, not a resume-from-pause dialog.
- **No visible timer/clock anywhere in the typer view.** WPM is computed and shown only *after* a paragraph is completed (not live-updating mid-paragraph, as far as observed), and it's derived from elapsed time between paragraph start/end under the hood — the timer is a backend calculation, not a UI element.
- **Zen Mode** is the closest thing to a "focus/pause the world" control, but it's a visual-declutter toggle, not a session pause.

**Recommendation for your build:** since Typersguild doesn't actually solve pause/timer well, this is a place to *improve on the source* rather than copy it — see §10.

## 6. Theme System

- Header has a palette icon opening a dropdown, grouped into **Dark Themes** and **Light Themes**, ~15 dark + ~10 light presets shown as three-dot color swatches + name (Catppuccin Mocha, Nord, Rosé Pine, Tokyo Night, Dracula, Solarized, Gruvbox, Ayu, Monokai Pro, One Dark Pro, Night Owl, Material, Charcoal, Grayscale, Black Metal, plus light equivalents: Cloud, Paper, Sakura, Catppuccin Latte, Solarized Light, etc.). Selecting one applies instantly, no save step.
- Separate **Custom Themes** settings section: build your own palette (down to caret color and error-highlight color) and save it alongside the presets.
- This is high-value, low-effort to clone: store themes as CSS-variable maps (background, foreground, muted/dim text, accent, error-red, caret) and let a JSON array define both the built-ins and user-created ones.

## 7. Settings — Full Page

Settings is its own route, organized via a single "Section" dropdown selector (not a sidebar) that switches the content below it. Two groups: **Platform** and **Account**.

### 7.1 Appearance
- Live preview box ("The quick brown fox jumps over the lazy dog") that updates as you change font, size, thickness, spacing.
- Font picker (defaults to "System Monospace"; should support importing other monospace fonts).
- Font Size slider (12–32px observed).
- Font Thickness slider (Normal + presumably Light/Bold).
- Letter/line spacing control (implied by "Normal spacing" in the preview caption).

### 7.2 Custom Themes
See §6.

### 7.3 Stats Card
A configurable floating widget shown during typing (or on the dashboard) — pick which metrics appear: WPM, accuracy, progress %, XP, etc. Observed preview: `72 WPM · 98.5 ACCURACY · [progress bar] 45%`.

### 7.4 Audio
- **Enable Audio** master switch.
- **Typing Sound** — a picker of mechanical-keyboard click sound packs (e.g. "Alpaca Switch," labeled with a style descriptor like "Smooth Linear"), each with a headphone-icon **preview/audition** button next to the dropdown so you can hear it before committing.
- **Volume** slider for typing sound (0–100%).
- **Error Sound** — separate picker (observed: "Buzzer") with its own preview button and its own volume slider, decoupled from the typing-click volume. Copy: "Audio feedback when making mistakes helps improve typing accuracy."

### 7.5 Keyboard
- **Show Keyboard** toggle — renders a full on-screen QWERTY keyboard graphic below the setting that highlights/visualizes key presses live as you type. Good for beginners; worth keeping optional and off by default.

### 7.6 Training & Behavior
Copy: "Configure how the typing trainer responds to mistakes and guides your learning."
- **Enable Training Mode** — master toggle for mistake-driven mechanics.
- **Training Behavior** dropdown, only visible when Training Mode is on — observed option: "Backtrack 3 Words on Error" ("When a mistake is made, the cursor will move back 3 words from the current position"). Implies multiple backtrack distances are selectable.
- **Ignore Capitalization** — type without matching upper/lowercase (on by default in the observed account).
- **Stop on Error** — hard-blocks further input until the mistake is corrected (off by default; mutually relevant with Training Mode's backtrack behavior — probably mutually exclusive in practice).
- **Auto Skip Symbols** — only require letters/numbers/spaces, auto-advance over punctuation.
- **Show Predictive Hints** *(Beta tag observed)* — highlights characters you personally tend to mistype, before you reach them, presumably driven by the digraph/trigraph mistake analysis (§8).

### 7.7 Account section
- **Notifications**, **Billing** — not applicable to a local single-user app; drop both, or repurpose "Notifications" as local desktop-notification preferences (e.g. "notify me of daily streak") if you want to keep a lightweight version.

## 8. Stats, Progress & "Gamification" Layer

Worth cloning because it's what makes the site feel alive rather than a bare typing drill:

- **XP** awarded per paragraph (scaled to length/difficulty) and even small amounts for headers (+2 to +6 xp) — every unit of text typed gives *something*, which is what makes scrolling through a whole chapter feel rewarding.
- **Per-paragraph stats** (wpm / accuracy / xp) persist inline in the text permanently — this doubles as a low-effort spaced-repetition signal: paragraphs you did badly on are visually flagged (lower accuracy number in place) so you know where you struggled without a separate report.
- **Rank / level** — XP total maps to a level with "N XP to level up"; rank is only meaningful with other users, so for a local app either drop it or repurpose as a personal-best/milestone tracker.
- **Digraph/trigraph mistake analysis** — "Smart Mistake Analysis" surfaces the specific two/three-letter sequences you mistype most (e.g. "th," "he," "er," "in," "an," "st") as chips, which is a genuinely useful, non-obvious feature for a self-improvement tool. This is what should feed the Predictive Hints beta feature.
- **Daily heat map** for streaks (contribution-graph style).
- **Vocabulary collection** — words encountered during typing that the system judged uncommon/notable get saved to a personal word list, shown as chips on the dashboard.

## 9. What Typersguild *doesn't* have to solve, but you do: document ingestion

Since this is for uploading your own docs rather than picking from a fixed catalog, you'll need a layer Typersguild doesn't show:

- **Upload & parse**: accept PDF, EPUB, DOCX, TXT, MD. Extract clean paragraph-level text (strip headers/footers/page numbers from PDFs — this is the fiddly part).
- **Auto-chaptering**: split into "chapters" by detected headings (H1/H2, "Chapter N," page breaks) with a manual override UI to merge/split sections, since your source docs won't be as cleanly formatted as Project Gutenberg texts.
- **Re-processing**: allow re-uploading a corrected version of a doc without losing typing progress already recorded against it (match by paragraph hash, not by index, so edits upstream don't silently shift your stats).
- **Cover generation**: since uploads won't have cover art, auto-generate a simple placeholder (Typersguild's public-domain covers are flat geometric shapes on a solid color — cheap and easy to replicate procedurally from a hash of the title).

## 10. Where to improve on the source (pause/timer, specifically)

You asked for this explicitly, and the honest answer from the walkthrough is that Typersguild's "pause" is really just "stop typing, come back later, autosave handles it" — there's no session clock in the UI. For a local personal tool, two small additions would genuinely help without adding complexity:

1. **A live elapsed-time readout** for the current paragraph/session (small, corner of the Stats Card widget) — cheap to add since you're already timing each paragraph server-side to compute WPM; just surface it live instead of only after the fact.
2. **An explicit Pause control** — freezes the timer (so idle time reading/thinking doesn't tank your WPM) and dims the text, with a single keypress (e.g. `Esc` or `Space` when not mid-word) to resume. This solves a real annoyance: right now, if you stop to think mid-paragraph, that dead time still counts against your WPM for that paragraph.
3. **Idle auto-pause**: if no keystroke for ~10s mid-paragraph, auto-pause the timer (not the session) so you're not penalized for interruptions, and resume timing on the next keystroke.

None of this exists in the source product as observed — flagging it as new scope, not a clone.

## 11. Suggested local stack (optional — you asked mainly about UI/UX, but since this is meant to run locally)

Given you work primarily in Python:

- **Backend**: FastAPI + SQLite (single file DB is plenty for one user's library + stats history). SQLite also makes "no auth, no accounts" trivial — this is a single-profile local app.
- **Doc parsing**: `pypdf`/`pdfplumber` for PDF, `ebooklib` for EPUB, `python-docx` for DOCX.
- **Frontend**: a small React (or even vanilla JS) SPA for the typer view specifically, since character-by-character diffing/coloring benefits from a real component model; everything else (dashboard, settings, library) can be simpler server-rendered pages if you want to minimize frontend surface area.
- **Audio**: bundle a handful of CC0 mechanical-keyboard click packs + a couple of ambient loops (rain/cafe/white noise) as static assets; Web Audio API for low-latency per-keystroke playback.
- **Local-only auth**: none needed — it's your machine. Skip the entire Billing/Notifications/Friends/Leaderboard surface area from §2.

---

## 12. MVP scope cut

If building incrementally, this is the order that gets you a usable tool fastest:

1. Upload → parse → chapter list → typer view with live char-by-char feedback (no themes, no sound, one font).
2. Per-paragraph WPM/accuracy/XP scoring + autosave + inline stats display.
3. Settings: Appearance (font/size) + Audio (one click sound + volume) — the two settings you'll actually miss first.
4. Dashboard: continue-reading card + basic WPM/accuracy trend.
5. Theme picker (clone 5–6 popular presets, not all 25).
6. Training & Behavior toggles, Quick Settings drawer, Focus Sounds, Zen Mode, vocabulary/digraph analysis — polish layer, add once the core loop feels good.
7. Pause/live-timer improvements from §10 — since these don't exist upstream, treat as a v2 differentiator once the clone is solid.
